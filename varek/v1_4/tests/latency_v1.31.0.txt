  Notes
  - Under a request rule the proxy decides the request on its head and streams the body;
    under an MCP rule it holds the body until it has read and parsed all of it, then
    decides the call and sends it, so the held column grows with the body.
  - 1 MiB is the default max_body of an MCP rule; a larger call needs max_body= on its rule.
  - The server is on this host: a real server's network time is not in these numbers.
